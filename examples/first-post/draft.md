## 4. Selected post

Title: Leave your next writing session three things

Before you close a draft, leave three things together: the text you selected, the source note behind it, and one sentence saying what to do next.

The next action can be small: shorten the opening, check a claim, or add the missing example. Make it specific enough that you can start there.

Next time, reopen the actual draft and source note before asking for edits. If you move the folder to another computer, check that the referenced files open there too.

You now have a concrete starting point for the next session. This is a suggested working habit, not a promise about time saved or automatic synchronization.
