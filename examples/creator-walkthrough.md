# Fictional walkthrough: a repaired desk lamp

**Everything in this example is fictional.** The source references below illustrate how to organize your own private evidence; they are not files supplied by this repository, verified events or publication receipts. This example ends at a draft waiting for footage. For a fictional structured post-release chain, see [full-lifecycle.example.json](full-lifecycle.example.json).

## Brief

Reader question: can a small repair make an old desk lamp useful again?

Takeaway: show one restored function and explain the limit of the check.

Author statement: “I like this lamp and wanted to use it again. Seeing the button work was the interesting part. I plan to keep using it and see whether it keeps working.”

Permitted hypothetical sources: `sources/repair-note.md` and `sources/button-check.mp4`, from the same repair revision. No adjacent family photos or account information are in scope.

| Claim | Type and support | Public wording / boundary |
| --- | --- | --- |
| The button previously did not switch the lamp on | observation, dated repair note | “The button used to do nothing.” |
| The button now switches it on in a short check | observation, post-repair clip | “Watch it switch on now.” |
| Long-term reliability | hypothesis, no prolonged test | Do not claim “fixed forever” |
| Repair cost and duration | unknown, no records | Omit figures |

This is a `candidate` because the changed source provides a visible result and a useful limitation. It is not a tutorial on electrical repairs and provides no safety or repair-method claims.

## Before and after editing

Rejected illustrative draft: “After hours of frustration, I finally fixed every problem. This lamp will last for years.”

Why rejected: no source supports hours spent, frustration, all problems or future lifetime. Natural-sounding detail can still be invented.

Selected fictional title: **The lamp I wanted to keep finally lights up**

Cover: **It lights up again**

Opening: “This button used to do nothing. Watch it now.”

Body: “I wanted to keep this lamp. After the repair, pressing the button switches it on again. That is the part I wanted to show.”

Ending: “This is one working check. I will see how it holds up in use.”

The last sentence is a stated future intention in this fictional author brief, not evidence of a completed long-term test. A real author must agree with any such commitment before using it.

## How to continue without inventing completion

After footage arrives, inspect it, adjust any unsupported present-tense claim, produce the edit and review the exact export. Prepare a destination package under the current requirements. Obtain or verify scoped authorization for the actual external action. Record actual platform status and management/public readback, then archive and measure at declared windows. If the platform only saves a draft, retain that fact; do not copy a fictional released state from another example.
