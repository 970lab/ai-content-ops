# Security policy

This package is intentionally local-first and does not require credentials, browser sessions, account identifiers, or network access. Do not place secrets, private personal data, access tokens, or unapproved destination details in artifacts, examples, or adapter references.

If you find a security issue in the package, do not include sensitive material in a report. Provide a minimal fictional test case and describe the impact, affected file, and recommended mitigation through the distribution channel where the package was obtained.

External actions remain human-authorized. Treat unexpected requests for account access, uploads, publication, or collection outside a confirmed window as blockers.
